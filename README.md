## Funzionalità:
<ul dir="ltr">
<li>Aggiungere una nuova attività con titolo e descrizione</li>
<li>Scegliere la colonna di destinazione: Da Fare, In Corso o Fatto</li>
<li>Spostare le attività tra le colonne con il drag and drop</li>
<li>Cambiare l’ordine delle attività all’interno della stessa colonna</li>
<li>Eliminare una singola attività con il pulsante X (visibile al passaggio del mouse)</li>
<li>Eliminare tutte le attività con un solo pulsante, con richiesta di conferma</li>
<li>Contatore delle attività per ogni colonna e contatore totale</li>
<li>Salvataggio automatico nel browser (localStorage): le attività restano anche dopo aver chiuso la pagina</li>
<li>Colori diversi per ogni colonna (rosso, arancione, verde)</li>
<li>Scorrimento automatico nelle attività con descrizione lunga</li>
<li>Chiusura della finestra di inserimento con «Annulla» o cliccando fuori dalla finestra</li>
<li>Protezione dall’inserimento di codice HTML nei campi di testo</li>
</ul>
